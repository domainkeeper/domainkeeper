## `01` — Who I Am

I'm **Pratham**, a **B.Tech CSE / AI-ML student** exploring the intersection of **software development, AI, and creative technology**.

I like taking ideas that exist only as concepts in my head and figuring out how to turn them into something real.

I naturally think visually — often imagining the interface, system, interaction, or experience before I know exactly how I'll implement it.

```text
IDEA
  ↓
VISUALIZE
  ↓
DESIGN THE SYSTEM
  ↓
BUILD A PROTOTYPE
  ↓
BREAK IT
  ↓
UNDERSTAND WHY
  ↓
BUILD IT BETTER
```

I'm not trying to present myself as someone who has mastered everything.

I'm learning.

I'm experimenting.

I'm building.

And I'm gradually becoming the developer I want to be.

### 🛰️ Sentinel AI

An AI-powered intelligence/automation system built around the idea:

> **AI that watches while you're away.**

The system is designed around a monitoring and reasoning workflow:

```text
USER GOAL
    ↓
SENTINEL
    ↓
SOURCES + MEMORY
    ↓
REASONING
    ↓
IMPORTANCE TEST
    ↓
IGNORE / RELEVANT
    ↓
ACTION
```

The core workflow explores:

**DISCOVER → FILTER → UNDERSTAND → COMPARE WITH HISTORY → DECIDE → ACT**

An exploration into **autonomous agents, monitoring, memory, reasoning, and useful automation**.

## `05` — How I Learn

I don't want to endlessly consume tutorials without creating anything.

My preferred loop is much closer to:

```text
          "Can I build this?"
                   │
                   ▼
              START BUILDING
                   │
                   ▼
               SOMETHING
                BREAKS
                   │
                   ▼
             WHY DID IT BREAK?
                   │
                   ▼
            LEARN THE CONCEPT
                   │
                   ▼
              FIX THE SYSTEM
                   │
                   ▼
             TRY SOMETHING
                HARDER
```

Some projects work.

Some don't.

Some prototypes become completely different projects.

Some get abandoned.

That's not separate from the learning process.

**That is the learning process.**
